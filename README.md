# Python Exercise Notebook

## About
This project began as making a notebook file for "[46 Simple Python Exercises](https://web.archive.org/web/20170430094258/http://www.ling.gu.se/~lager/python_exercises.html)" by Torbjörn Lager. As I began typing up the prompts, I made some small adjustments to the text. If I was adjusting the text, I might as well adjust the order of the exercises too. I kept a blank copy in case I decided to share it later. When I was attempting the exercises, I also made some other functions to assist in multiple exercises. I added these to the blank copy, to help others attempt the problems.

## Getting Started
1. Download, clone, or fork the repository to your device.
2. Work through the notebook and write code corresponding to each exercise.
